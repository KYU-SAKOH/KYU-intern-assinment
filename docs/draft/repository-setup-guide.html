テンプレートを自分のGitHubリポジトリにする手順

長期インターン選考プログラム デモシステム開発課題 ／ このガイドはリポジトリのREADMEを開く前、ZIPファイルを受け取った直後に行う

あらかじめインストールするツール
  • エディタはVS Codeを推奨。使い慣れたエディタがあればそちらでも構わない（DevContainerでの起動に対応していること）
  • Windowsの場合、この後インストールするDocker DesktopはバックグラウンドでWSL2（Windows Subsystem for Linux）を利用する。インストール時にWSL2のセットアップを求められたら案内に従う（詳細: Docker DesktopのWSL2バックエンド）
  • AIツールはClaude Codeを使用する。アカウントはインターン担当者から共有する
  • 課題内のAI機能（問い合わせへの一次回答など）を実装する際は、Gemini APIの無料枠などを利用する（追加コストなく実装できる）

0. 事前に用意するもの

  • Git（Windowsの場合、インストール時に一緒に入る「Git Bash」をターミナルとして使うのがおすすめ）
  • GitHubアカウント（すでに持っていればそれを使う）
ゴール: ターミナルで git --version を実行してバージョンが表示される。かつGitHubに自分のアカウントでログインできる。

1. ZIPファイルを展開する

受け取ったZIPファイルをダブルクリックして展開し、わかりやすい場所（デスクトップなど）に置く。

2. 自分のGitリポジトリとして初期化する

展開したフォルダをターミナルで開き、以下を実行する。

cd <展開したフォルダ>
git init
git add -A
git commit -m "chore: initial commit"
初めてGitを使う場合は、git commitの前に一度だけ以下を実行して自分の名前とメールアドレスを設定しておく。
git config --global user.name "自分の名前"
git config --global user.email "自分のメールアドレス"

3. GitHubで新しいリポジトリを作成する

  1. github.com/new を開く
  2. Repository name を入力する（例: my-intern-assignment）
  3. Public を指定すること
  4. README・.gitignore・ライセンスは追加しない（チェックを入れない）。追加すると、次の手順のpushで履歴がぶつかってしまう
  5. 「Create repository」を押す

4. 作成したリポジトリにpushする

作成後の画面に表示されるリポジトリのURL（https://github.com/自分のアカウント名/リポジトリ名.git）を使い、ターミナルで以下を実行する。

git remote add origin <作成したリポジトリのURL>
git branch -M main
git push -u origin main
初回push時にログインを求められることがある。GitHubはパスワードでの認証を廃止しているため、以下のどちらかで認証する。
  • Personal Access Tokenを作成し、パスワード欄に貼り付ける
  • GitHub CLIをインストールし、gh auth loginでブラウザ経由で認証する（迷ったらこちらがおすすめ）
ゴール: 自分のGitHubアカウント上に、このテンプレートの中身が入ったリポジトリができている。ブラウザでそのリポジトリを開き、ファイル一覧と README.md が表示されればOK。

次にやること

ここまで完了したら、GitHub上の自分のリポジトリを開き、README.mdの案内に沿ってローカル環境を起動する（VS Code・Docker Desktopのインストール、DevContainerでの起動）。
